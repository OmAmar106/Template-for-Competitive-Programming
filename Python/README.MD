# Python Snippets

This folder contains the VS Code Python snippets and their generated code files.

- **`python.jsonc`**: Contains the Python snippets exactly as they are stored in VS Code, without any modifications.
- **`python_snippet_files/`**: Contains the individual code files generated from `python.jsonc` using GitHub Actions.

Whenever `python.jsonc` is updated, GitHub Actions automatically regenerates the corresponding files in `python_snippet_files/`.
